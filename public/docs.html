Embed the booking widget

<script src="/widget.js" data-restaurant="demo"></script>
<iframe src="/book/demo?embed=1" style="width:100%;height:900px;border:0" title="Book a table"></iframe>

The widget posts {type:"tablesimple:height"} and {type:"tablesimple:booked"} messages to the parent page. Framing is allowed from any site.

Wix

  1. In the Editor click Add (+) → Embed Code → Embed HTML.
  2. Choose Code, paste Option A (or B), click Update.
  3. Drag the box to full width and ~900px tall (Wix boxes have a fixed height, so give it room). Publish.

Shopify

  1. Online Store → Themes → Customize, open the page you want.
  2. Add section → Custom Liquid (or "Custom HTML").
  3. Paste Option A or B, Save. To use a dedicated page, create Pages → Add page "Reservations" and pick it in the customizer.

Squarespace / WordPress

Squarespace: add a Code block and paste. WordPress: add a Custom HTML block and paste.

Public endpoints (no key, CORS enabled)

GET  /api/public/{slug}                       restaurant name + hours
GET  /api/public/{slug}/availability?date=YYYY-MM-DD
     → {"date","open":true,"slots":[{"time":"17:00","remaining":20},...]}
POST /api/public/{slug}/bookings
     {"date":"2026-11-06","time":"19:00","partySize":2,"name":"Ana","phone":"555-0100","notes":""}
     → 201 {"id":"bk_...","status":"confirmed",...}  | 409 if full

Restaurant endpoints (header X-API-Key)

GET    /api/v1/restaurant                     full settings
PUT    /api/v1/settings                       {name,openDays:[0-6],open:"17:00",close:"22:00",
                                               slotMinutes,capacity,maxParty,closedDates:["YYYY-MM-DD"]}
GET    /api/v1/availability?date=YYYY-MM-DD
GET    /api/v1/bookings?date=YYYY-MM-DD       (omit date for all; &includeCancelled=1)
POST   /api/v1/bookings                       same body as public booking
DELETE /api/v1/bookings/{id}                  cancels; frees the seats
curl -H "X-API-Key: rk_demo_bella_2026" "/api/v1/bookings?date=2026-11-06"

openDays: 0=Sun … 6=Sat. Capacity is seats per time slot; a booking uses partySize seats.
